# Интеграционный промпт HOOKAH POS: сведение веток без потери результата

## Цель
Собрать единый проверенный release из параллельных веток HOOKAH POS. Сохранить завершённые и незавершённые направления, устранить дубли и конфликты, затем публиковать только проверенный результат.

## Порядок работы
1. Зафиксировать карту веток: имя, последний коммит, домен, статус, зависимости и что уже опубликовано на VPS.
2. Сохранить исходные ветки и создать резервные теги перед интеграцией. Ничего не reset/delete в исходных worktree.
3. Взять `origin/codex/current-release` как базу публикации.
4. Сводить пакетами в порядке зависимостей: каркас и навигация; аутентификация и tenant/role; персонал и роли/права; склад; финансы и зарплата; лояльность; визуальные и Fold/mobile исправления.
5. Для каждого пакета сначала сравнить diff и найти первопричину конфликтов. Не переносить коммиты вслепую и не дублировать уже вошедший код.
6. После каждого пакета проверять синтаксис, контракты маршрутов/ролей/API и затронутые пользовательские сценарии. Сохранять совместимость существующей базы данных.
7. Повторно пройти канонические страницы в desktop и Fold/mobile, сделать скриншоты, исправить только подтверждённые дефекты и записать результат в `docs/ai-team/WORK_LOG.md`.
8. Только после успешной проверки обновить remote release и развернуть на VPS через штатный backup/health-check сценарий. Сразу проверить главные маршруты, роли владельца/администратора, старые и новые назначения сотрудников.

## Правила границ
- Соседние чаты и ветки считаются источниками изменений; одна и та же функция не реализуется повторно.
- Ветки не удалять, незавершённые направления не терять: либо интегрировать, либо явно пометить как отложенные с причиной.
- Не смешивать визуальный polish с изменением бизнес-логики без проверки обоих контрактов.
- При конфликте приоритет: сохранность данных и tenant/role security, затем функциональная совместимость, затем визуальная консистентность.
- Итоговый отчёт должен содержать: карту интеграции, вошедшие коммиты/пакеты, конфликты и решения, проверки, статус VPS и оставшиеся этапы.
