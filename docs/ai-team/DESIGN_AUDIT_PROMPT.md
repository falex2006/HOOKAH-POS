# Промпт дизайн-аудита Hookah POS

Проведи полный визуальный аудит Hookah POS по маршрутам `/admin`, `/orders`, `/clients`, `/reservations`, `/delivery`, `/inventory`, `/finance`, `/integrations`, `/network` и связанным подразделам меню. Каждый маршрут проверить в desktop (ширина 1440–1536) и Fold/mobile (ширина 360–412, высота 800–915).

Для каждого экрана зафиксировать скриншот и проверить: масштаб интерфейса, боковое меню, верхнюю панель, заголовок, сетку, единообразие шрифтов и кнопок, размеры полей, выравнивание, переносы, переполнение, горизонтальный скролл, пустые/ошибочные состояния, модальные окна, активные состояния и доступность действий.

Составить дефекты с маршрутом, режимом, воспроизводимым сценарием, ожидаемым видом и приоритетом P0–P3. Исправлять первопричину через общие design tokens и responsive правила, сохраняя API, роли, маршруты и tenant-изоляцию. После каждой группы правок повторить desktop/Fold скриншоты и проверить, что не появились регрессии.

Порядок работы: общий каркас и адаптивность → меню и верхняя панель → типографика/кнопки/поля → страницы по разделам → модальные окна и состояния → финальный сквозной QA. Не добавлять временные тестовые данные и не публиковать незавершённые правки.
