# Цветные карточки оперативной полосы

11.10.2026. Пользователь уточнил визуальную претензию: три карточки в согласованном рендере имели цветные поверхности и крупные значки, а реализация выглядела как одинаковые серые рамки. Выполнена отдельная локальная итерация именно этой области.

## Изменение

- «В приготовлении» — коралловый акцент существующего `--ui-link`; «Готовые заказы» — `--ui-success`; «Открытые счета» — `--ui-warning`.
- Поверхности получают мягкую примесь акцента 8% к `--ui-panel`, hover 12%; рамка и текст подчёркивают направление. Новых raw цветов, градиентов и свечения нет.
- Значки увеличены с 20 до 32 px, числа с 24 до 28 px через `--ui-font-page`. CSS-chevron состоит из декоративной рамки, без текста и дополнительных кнопок.
- Недоступные данные сохраняют «—», нейтральный фон, muted у всех дочерних элементов и скрытый chevron. Цветная карточка не выдаётся за успешно прочитанные данные.

Смысл, единицы, доступность по ролям, counts и click handlers сохранены. Коралловое приготовление не вводит признак срочности. «Открытые счета» не переименованы в просьбу гостя об оплате; готовность остаётся проверкой всех строк заказа.

Product delta: только `pos-workspace.css` и его `dist` копия, CSS revision в `index.html` / `dist/index.html` с 1 на 2. Общий shell, остальная геометрия рабочего места, API, JS, RBAC, деньги и БД этой итерацией не менялись. База предыдущего counter CSS SHA-256: `1BBF365C31FB07A7847647B07B7969375F5092573EFF7AD2680F2099BF10189E`; контрольная копия сохранена в ignored task archive.
