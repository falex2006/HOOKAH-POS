# Visual QA — рабочее место сотрудника

Дата: 2026-10-11. Проверено в реальном локальном приложении Chrome/Playwright на изолированной QA БД, обе темы, scale factor 1. Production не проверялся. Визуальный аудит не отправлял API-записи; форма оплаты только открывалась и закрывалась.

## Viewport и доступность действия

| Viewport | Карточка заказа: верх / низ, px | Главный CTA: верх / низ, px |
|---|---:|---:|
| 1366×768 | 213 / 752 | 691 / 739 |
| 1920×1080 | 213 / 1064 | 1003 / 1051 |
| 768×1024 | 78 / 1008 | 947 / 995 |
| 390×844 | 74 / 828 | 767 / 815 |
| 320×740 | 74 / 724 | 663 / 711 |

Геометрия одинаковая в двух темах. Главный CTA имеет высоту 48 px; проверенные цели карточки — минимум 44×44 px. Прокрутка внутренней области заказа не перемещает итог и CTA. На 1366×768 длинный заказ имел scrollHeight 880 px при внутренней области 308 px. Горизонтального переполнения страницы на пяти размерах нет. Раскрытая область «Ещё действия» имеет высоту 286–384 px, не вытесняет CTA и закрывается по Escape с возвратом фокуса. Enter открывает её; клавиатурный фокус CTA виден, outline 3 px. При reduced-motion проверенные переходы равны 0s, animation none.

## Фактический контраст

Рассчитана относительная яркость sRGB по computed styles и прилегающей непрозрачной поверхности; для текста учтена opacity самого элемента и родителей. Значения относятся к видимым сохранённым состояниям зала, заполненного заказа, вторичных действий, очереди и открытой оплаты.

| Проверка | Dark | Light |
|---|---:|---:|
| Минимум текста оперативной полосы / заказа | 6,81:1 | 5,81:1 |
| Минимум текста очереди после исправления opacity | 9,34:1 | 5,81:1 |
| Минимум текста оплаты | 6,81:1 | 6,81:1 |
| Главный CTA | 6,81:1 | 6,81:1 |
| Количество / кнопки ± | 16,28:1 | 13,39:1 |
| «Гости» | 10,54:1 | 7,62:1 |
| Кнопки вторичных действий, минимум | 7,82:1 | 6,81:1 |
| Значимые границы контролов относительно соседней поверхности, минимум | 4,11:1 | 3,60:1 |
| Значимые иконки новых компонентов, минимум | 6,81:1 | 5,81:1 |
| Badge «Бар ожидает» | 11,43:1 | 6,85:1 |
| Badge «Бар готов · +1» | 11,02:1 | 6,49:1 |

Измеренный текст проходит 4,5:1, значимые границы и иконки — 3:1. Декоративные разделители `--ui-border-subtle` не считаются границами, необходимыми для распознавания действия. Найденное наследованное opacity 0,7 у подписи очереди и small снижало light contrast до 3,62/3,39:1; координатор установил scoped opacity 1. Повторное измерение подтверждает alpha 1 и проходящий контраст.

## Бейджи и длинные названия

Финальные badges используют helper 12 px, отступы 4/8 px. «Бар ожидает» занимает 92,83 px; «Бар готов · +1» — 94,70 px. В обоих залах, пяти viewport и двух темах пересечений текстов badge с названием, статусом и суммой не обнаружено. Бейджи сохраняются после смены зала, размера столов и «Вместить»; проверен клавиатурный tablist и агрегация разделённых счетов — см. [floor-qa.json](evidence/floor-qa.json).

Фактические имена QA таблиц короткие. Дополнительно проверен явно обозначенный ответ API только для отрисовки: один зал с десятью столами, длинное имя и PS5/ТВ, без изменения БД. В dark/light при 1366×768 и 320×740 overlap названия / суммы / статуса с badge отсутствует; полное имя сохраняется в aria-label. Это доказательство компоновки, а не сохранения таких настроек через API.

Это ограниченная визуальная приёмка указанных состояний, не полный WCAG-аудит. Реальный POS сенсорный терминал, Windows scaling, Edge, физический Fold / складной экран, шарнир, аппаратная клавиатура и экранная клавиатура телефона не измерялись. Mobile viewport проверен эмуляцией настольного Chrome; физический Fold не объявляется проверенным. Все варианты ошибок, placeholders, disabled-состояний и сохранение темы не покрываются данным визуальным отчётом; функциональные и state проверки документированы отдельно. Старые брендовые элементы общего sidebar/header вне области новых компонентов здесь не сертифицированы.
