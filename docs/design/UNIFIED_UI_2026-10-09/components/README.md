# Эталон UI-02.2

Локальная демонстрация общих контролов. Не входит в production маршруты или меню и не читает/сохраняет продуктовые данные.

Из корня репозитория:

```powershell
node scripts/ui-component-reference-server.cjs
```

Открыть `http://127.0.0.1:31957/`. Сервер слушает только loopback; остановка — Ctrl+C. Файлы и пять существующих Manrope fonts перечислены в allowlist, сетевые обращения из страницы запрещены CSP. Открытие HTML напрямую через file URL не заменяет этот preview.

## Как подключать на следующем экране

1. Добавить `.ui-components` на контейнер согласованной области миграции. Тема берётся из действующих `.portal.light-theme` / `.staff-theme.light-theme` и semantic tokens.
2. Выбрать вариант из [каталога](../COMPONENT_CATALOG.md). Не заменять все legacy классы одним проходом.
3. Сохранить native элементы и поведение: `button` с явным type, `select`, `input`, `textarea`, checkbox внутри кликабельного label. Badge пассивен; icon button получает имя через `aria-label`.
4. Связать label/help/error через уникальные ID, `aria-labelledby`, `aria-describedby`, `aria-invalid`. Disabled — native `disabled`; readonly остаётся доступен выделению. `aria-disabled` на ссылке само по себе не блокирует действие.
5. Для ожидания использовать резерв места, `aria-busy`, native disabled и guard обработчика. В примере `[aria-hidden]` скрывает неактивный текст, сохраняя его геометрию. Не подменять его `hidden`: legacy `[hidden] !important` схлопывает место.
6. Проверить обе темы, длинный текст/числа, keyboard, empty/loading/error и повторное нажатие. Не переносить локальный 5-секундный таймер в продуктовую логику.

Примеры: [HTML](UI_02_2_REFERENCE.html), [состояния](ui-component-reference.js). Семантические роли и геометрия — [DESIGN_TOKENS](../../../../DESIGN_TOKENS.md). Browser helper запускается только внутри документированного `cua_repl` с переданным tab; это не самостоятельный browser driver.

## Границы

Ручное уменьшение движения в эталоне проверено. OS media query разобран CSSOM и соответствует ручному набору деклараций, но системное предпочтение в доступном браузере было false; фактическое включение через ОС не проверено. Длинный текст collapsed native select может обрезаться; значение сохраняется целиком. Для многословных категорий на конкретном экране потребуется подходящий UX.

Legacy контролы, mobile/Fold и полный role×state прогон не приняты этим эталоном. [Итог UI-02.2](../UI_02_2_RESULT.md) содержит замеры и доказательства.
