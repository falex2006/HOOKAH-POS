2026-10-10. **ACCEPTED_SCOPED_WITH_DOCUMENTED_DEBT**, только локально.

## Изменения

- Административные страницы используют существующие семантические поверхности обеих тем и общий контекст заголовков. Staff сохраняет плитки/список/таблицу, размер плиток 1–4, пять колонок и персональные настройки. Длинные названия переносятся, таблица прокручивается локально; основные действия имеют область 44px.
- Пользовательские/системные роли и назначение профиля используют настоящий общий редактор C11: фокус, клавиатура, локальный черновик, ошибка с сохранением ввода, блокировка закрытия/повторного submit при ожидании ответа. Owner-only действия и прежняя форма API сохранены.
- Чтение ролей, журнала, смены, диагностики и лояльности различает загрузку, ошибку, отсутствие данных и повтор. Устаревшие/отсоединённые ответы не подменяют текущий экран. Действия смены и экспорт журнала недоступны при неуспешном чтении. Правила лояльности заблокированы до успешного GET.
- Редактор программы лояльности раскрывается отдельно от списка, получает фокус и сворачивается с сохранением формы; полноценная миграция этого редактора в C11 не заявлена. Версии правил, скидки, бонусы, депозит и формулы акций сохранены.
- Уведомления имеют явную информационную страницу с открытием существующего центра и честным сообщением при его недоступности. Обращение в help сохраняется только локально; ошибка storage не очищает форму и не выдаёт успех. Внешние сообщения не отправлялись.

## Ограничения и унаследованный долг

- Полная desktop матрица относится к UI-09.1. Edge, Fold/UI-10.1, полный WCAG/контраст, все ошибки в обеих темах, полный staff/PIN/password/shift/accounting lifecycle здесь не приняты.
- Layout исходно не имеет отдельной sidebar-link; контекст есть в H1/header/локальном центре настроек. Пустой selectedNavigation на этом hash не выдан за успешный активный sidebar item. Дублирующиеся H1/H2 смены/журнала/справки и зелёный значок при ошибке смены остаются прежними.
- Company UI ограничения manager уже, чем некоторые серверные возможности; staff selector зависит от прежних staff/settings прав. Ролевая модель и серверные permissions не расширены.
- Server other-target PIN защита (staff_manage без достаточного target-role контроля), lock.js игнорирование non-OK PATCH prefs, CSV formula escaping журнала и отдельные legacy async/lifecycle участки — самостоятельный долг; данный визуальный этап их не исправляет.
- Лояльность сохраняет прежние значения/version/math. Help — локальный список обращений, а не доставка сообщений. Тестовая неназначенная роль остаётся в изолированной БД для аудита.
