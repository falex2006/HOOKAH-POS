## Контракты и итоговый diff

- Пустой зал и выбранный зал без столов используют общий `emptyFloorMarkup`. Ссылка настройки доступна только при подтверждённой сессии и permission `settings`, что соответствует контракту редактора и API настройки залов. `preserveWorkspaceRoute` сохраняет рабочий контекст, URL экранируется. Остальным пользователям показано обращение к владельцу или управляющему.
- Правая панель сообщает о необходимости настройки только после успешной загрузки схемы (`floorReady`) и при отсутствии столов во всех залах. Обновление панели после загрузки ограничено заказом со столом либо состоянием без id; существующий отдельный заказ не получает дополнительные запросы сводки/оплат при каждом опросе схемы.
- Дата показателей смены обязательна, ограничена диапазоном `0001-01-01`–`9999-12-31`; до API проверяются четырёхзначный ISO-год, native validity, конечность даты и обратное преобразование. Неверная дата очищает выбор смены, обновляет существующий custom select, убирает старые показатели и выставляет `aria-invalid`. Валидная дата восстанавливает обычную загрузку.
- Счётчик revision увеличивается до локальной проверки: старый ответ не заменит сообщение об ошибке. Начальная загрузка по-прежнему не отправляет дату и принимает дату заведения от сервера. Ограничения employeeView и серверные проверки не изменены.
- Остальные изменения — cache revisions и синхронизированные публикационные копии. Все 35 изменённых HTML-файлов проверены на отсутствие изменений кроме revisions. SHA-256 исходника и dist совпали для `app.js`, `portal.js`, `portal-session.js`. `git diff --check` прошёл.
