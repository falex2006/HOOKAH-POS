# MT-04 — оформление управленческих страниц

Дата: 2026-10-11. Статус: реализовано локально; общий выпуск после MT-05.

## Реализация

Применены общие компоненты MT-03 к главной, складу, меню и технологическим картам, финансам/зарплате/отчётам, гостям, заказам, броням, задачам, доставке и настройкам. Добавлены domain selectors для карточек показателей, списков, редакторов, диаграмм и состояний. Фирменная кораллово-оранжевая палитра, тонкие границы, семантические статусы и светлая/тёмная схемы сохраняются. Формат сумм, источники, периоды, API, права и бизнес-вычисления не менялись.

Native редакторы справочников склада и финансовых категорий получают тему на своём точном корне. Асинхронные окна передают ticket исходного инициатора до await; critical dialog поддерживает ticket отдельно для каждого открытия и явный null. Исправлена привязка окна поступления: после перерисовки toolbar используется текущая подключённая кнопка. 51 обработчик получает scoped notice binder; позднее сообщение не захватывает чужой контекст. Дополнены отступы форм зарплаты и сторно.

Рабочее место сотрудника, зал/столы, персонал, права, профиль и lock/PIN исключены. Native браузерные confirm/prompt/date picker/validation сохраняют браузерный внешний вид. Фоновые сообщения без доказанного инициатора сохраняют исходное оформление.
