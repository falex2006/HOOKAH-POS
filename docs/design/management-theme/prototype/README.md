# Интерактивный образец MT 02

Локальный образец управленческой темы Hookah POS. Примерные данные, роль и результаты действий симулируются. Никакие оплаты, поступления, возвраты или изменения клиентской базы не выполняются. Сервер приложения и его API не подключены.

## Запуск

Из корня проекта:

```powershell
node docs/design/management-theme/prototype/preview-server.cjs
```

Открыть URL `MT02_PREVIEW`, напечатанный сервером. Порт выбирается автоматически, адрес доступен только на компьютере через `127.0.0.1`. Остановка — Ctrl+C в процессе сервера. Запуск не требует `.env`, PostgreSQL или логина.

Для повторного запуска на том же адресе можно передать порт: `node docs/design/management-theme/prototype/preview-server.cjs 39490`.

Сервер отдаёт только index.html, prototype.css/js, действующий `assets/tabler-icons.svg` и явно перечисленные локальные brand/font assets. Остальные пути возвращают 404, запись POST — 405. Content Security Policy запрещает сетевые соединения приложения и отправку форм. Нет листинга папок проекта.

## Назначение

Главная, склад и компоненты демонстрируют одну тему: одинаковые размеры действий, читаемые показатели, таблицы, формы, окна и feedback. Переключатели образца не являются новыми пунктами реального приложения. Черновики и уведомления живут в памяти страницы; после reload состояние сбрасывается.

Роль в образце — визуальный сценарий, не проверка доступа. Набор прав реального приложения определяется сервером. Образец не заменяет приёмку API, tenant isolation или финансовых расчётов.

Результаты браузерной проверки и изображения перечислены в [MT02_RESULT.md](../MT02_RESULT.md). Образец не подключён к production bundles/source-dist и не предназначен для автоматического развёртывания.
