# MT-02 — интерактивный образец

Дата: 2026-10-11. Статус: образец выполнен, представлен для визуального согласования. Внедрение в приложение — MT-03/04 после согласования.

## Результат

Локальные HTML/CSS/JS: [prototype/index.html](prototype/index.html). Запуск и границы — [README](prototype/README.md). Сервер запускается командой `node docs/design/management-theme/prototype/preview-server.cjs`; URL с автоматически выбранным портом печатается в терминале.

- Главная: показатели с периодами, пример недельного графика, внимание, смена и финансовая готовность.
- Склад: таблица, поиск и фильтр, длинные данные, пустой список, отсутствие совпадений, загрузка, ошибка, подтверждённый ноль и неизвестные остатки.
- Компоненты: длинная форма, обязательные/необязательные и недоступные поля, ошибки и черновик, бронь из трёх шагов, критическое окно, legacy подтверждение, toast и немодальный центр уведомлений.
- Графитовые поверхности, обязательная фирменная кораллово-оранжевая палитра (`#ff516e` → `#ff9a3d`), единые высоты кнопок, текстовые статусы. Эффекты ограничены; CSS учитывает reduced-motion. После замечаний пользователя золотой брендовый акцент заменён, обводка клавиатурного фокуса уменьшена с 3 до 1 px с отступом 2 px; warning сохраняет отдельный янтарный цвет.

Все значения и операции демонстрационные. Симуляция роли не проверяет реальные права. В памяти страницы есть черновики и блокировка неизвестного исхода; reload начинает новый демонстрационный сеанс. Сброс critical явно начинает новую симуляцию и не подтверждает прошлую операцию.

## Проверка в браузере

Codex in-app browser, viewport 1440×900; временный override снят после проверки. Проверены:

| Сценарий | Наблюдение |
| --- | --- |
| Главная и склад | Реальные снимки; нет пересечения кнопок и текста в проверенных видах |

| Неизвестные остатки | Сводка и стоимость — «—», готовые суммы не остаются |
| Подтверждённый ноль | Остатки и стоимость 0, не маскируются знаком неизвестности |
| Пустой склад + управляющий | Динамическая кнопка добавления disabled |
| Пустое обязательное поле | Общее сообщение, ошибка у названия и фокус на поле |
| Сохранение формы | Во время ожидания повтор и закрытие disabled; ошибка сохраняет название |
| Закрыть и открыть форму | Черновик восстановлен; фокус после закрытия возвращён к кнопке |
| Бронь | Переход к деталям, назад с сохранением имени, итог перед подтверждением; pending отображается |
| Critical unknown | Нет успеха; повтор disabled после закрытия и повторного открытия |
| Клавиатура окна | Native modal; следующий Tab после обхода возвращает фокус внутрь; Escape закрывает обычную форму и возвращает фокус |
| Уведомления | `show()` без `:modal`; отметка прочитанного даёт 0, история остаётся; отдельно показан пустой центр |
| Важная ошибка | Текст о сохранении ввода и ручном закрытии; сообщение отображается в регионе уведомлений |
| Console | В просмотренном сеансе нет error/warn |

Снимки локального сеанса находятся в `tmp/mt02-preview-qa/`: `home.png`, `warehouse.png`, `long-form.png`, `critical-unknown.png`. Это доказательства отдельного образца, не production. Временные материалы не входят в коммит.

## Проверка исходников и изоляции

[Code health review](MT02_HEALTH_REVIEW.md): итог PASS. Замечания к согласованности состояния склада, повтору неизвестного исхода и устаревшим retry устранены. Архитектор уточнил немодальность tray и согласованность времени смены; правки внесены.

`node --check` для JS и сервера — PASS. Сервер слушает только loopback, отдаёт whitelist; `.env` возвращает 404, POST — 405, шрифт — 200. CSP запрещает connect и отправку форм. Нет fetch, авторизации, storage, изменений API/БД/dist.

Не выполнены и не заявляются: полная WCAG/контрастная сертификация, отдельный runtime прогон reduced-motion, screen reader, реальные права/tenant/финансовые операции, mobile/Fold, матрица браузеров. Эти ограничения не превращают образец в приёмку рабочего приложения.

## Следующий шаг

### Доработки по итогам просмотра владельцем

Фирменная палитра обязательна. Иконки заменены на существующий `assets/tabler-icons.svg`; самодельный sprite удалён. Поля используют одну границу при фокусе; кнопки и checkbox сохраняют отдельный тонкий keyboard focus.

Все выпадающие списки образца теперь используют графитовый combobox/listbox с коралловым выделением и группами. Нативный select скрыт, остаётся моделью значений формы; popover обеспечивает отображение поверх модального окна. Названия «Критическое действие» и «Подтвердить 3 200 ₽» заменены на «Возврат денег» и «Подтвердить возврат 3 200 ₽». Кораллово-оранжевый — основное обычное действие, серый — второстепенное, красный — опасное, зелёный — подтверждённый успех, янтарный — предупреждение.

Финальный просмотр в in-app browser: открытый список с группами, End/Enter выбирают пункт, Escape отменяет выбор, Space открывает, Tab закрывает; список внутри modal видим, при pending trigger disabled; выбор «Неизвестно» обновляет склад. Console error/warn отсутствуют. Type-ahead, reset и error-focus дополнительно проверены по исходникам, без отдельного заявления о полной проверке screen reader. Снимки: `tmp/mt02-preview-qa/themed-dropdown-final.png`, `return-money-final.png`. Изменения ограничены образцом, preview-server и документацией.

Согласовать внешний вид и затем MT-03: перенести общие компоненты в ограниченную управленческую тему с сохранением действующих контрактов. Страница сотрудников, рабочее место сотрудника, столы и зал исключены. Production, база клиентов, цеха и категории на этом этапе не изменялись.
