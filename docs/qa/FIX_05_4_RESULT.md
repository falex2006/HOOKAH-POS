# FIX-05.4 — сохранение групповой скидки

Дата: 08.10.2026. Статус: исправлено локально.

## Причина и изменение

После первого платежа цена читается из канонического снимка. Эта ветка `pgOrderPricing` возвращала название, ID и процент группы, но пропускала базу и сумму групповой скидки. Последняя оплата передавала отсутствующие поля в UPDATE как SQL NULL. Предыдущая проверка преобразовывала NULL через Number в 0, поэтому FIX-05.3 описывал симптом как 0/0.

В `server.js` оба поля восстановлены только из неизменяемых фактов снимка: база равна сохранённому subtotal при наличии группы; сумма равна сохранённой скидке, если группа выиграла, иначе 0. При отсутствии группы оба поля равны null. Текущие правила группы и акции не пересчитываются. Общий reader используется и последним платежом, и явным закрытием заказа. SQL записи, tenant guards, транзакции, правила начисления бонусов и структура БД не изменялись. Исторические записи не переписывались.
