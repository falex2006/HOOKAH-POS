# FIX-02 — права в интерфейсе

08.10.2026. **Выполнен локально.** Публикация на GitHub и production не выполнялась.

## Что исправлено

1. Портал сначала получает актуальную серверную сессию. До проверки защищённый интерфейс скрыт. Кэш и базовая роль больше не расширяют выданные сервером права.
2. Меню, прямые адреса и административные подразделы проверяют доступ согласованно. «Гости» открываются бармену и кальянщику по праву заказов, без выдачи кадровых прав.
3. Открытые страницы проверяют сессию при возвращении во вкладку и каждые 30 секунд активной работы. Выдача и отзыв прав обновляют интерфейс без повторного входа. Портал перезагружается при изменении прав, чтобы заменить обработчики со старыми разрешениями.
4. При ошибке проверки доступ закрывается и предлагается повтор. Старые ответы и поздний 401 не восстанавливают отозванные права и не удаляют новую сессию. На рабочем экране очищаются недоступные заказ, каталог и зал.
5. Владелец видит в карточке сотрудника сохранённые итоговые права и их источник. Пояснены персональное наследование, приоритет пользовательской роли и максимум системной роли.
6. Административные переходы учитывают реально выданные направления. Кнопки создания и изменения сотрудников дополнительно соблюдают серверные ограничения должности и целевой роли.
7. Обновлены runtime assets и их версии: portal472, bootstrap1, app204, login99, staff-card12. Root/dist синхронизированы; новый bootstrap включён в Docker и static allowlist.

## Проверка

- **12 связанных автоматических наборов PASS**, включая 84 сочетания должностей и кадровых действий; syntax и diff checks PASS.
- Edge: владелец, ограниченный администратор, управляющий, бармен, кальянщик. Размеры 1366×768 и 1920×1080.
- На синтетическом бармене: запрет персонала → выдача прав → автоматическое открытие в той же вкладке → отзыв → автоматическое закрытие → восстановление исходного пустого персонального списка и рабочего зала.
- Управляющий: склад только для просмотра; кадровая страница без кнопок изменения; редактор ролей запрещён. Ограниченный администратор: базовые права не добавились, прямой склад запрещён.
- Контролируемая остановка только собственного локального сервера: открытый склад скрыт, показана ошибка с повтором. После запуска и повтора склад загрузился снова.
- Архитектурная и независимая проверка кода выполнены с субагентами. Подробности и снимки перечислены в [FIX_02_QA.md](FIX_02_QA.md).

## Границы и дальнейшая работа

Полная регрессия проекта и все сочетания ролей в браузере не заявляются: ранее выполненные 926 PostgreSQL проверок FIX-01 здесь не повторялись. Изменение прав может перезагрузить портал и сбросить несохранённый ввод; формы не отправляются повторно автоматически. Сервер проверяет разрешения каждого запроса независимо от интервала обновления UI.

Права тестового бармена восстановлены, временные вкладки закрыты, эмуляция размеров сброшена. Локальный сервер 31932 восстановлен. Чужие рабочие файлы сохранены.
