# FIX-04.1 — понятная причина отказа оплаты

Дата: 08.10.2026. Локальная синтетическая среда, без публикации.

## Что исправлено

Окно оплаты скрывало конкретную серверную ошибку техкарты/остатков за общим предложением проверить сумму. Теперь оплата и закрытие стола используют общий перевод 11 ошибок. Сотрудник видит причину, предложение обратиться к управляющему и повторить действие после исправления. При оплате дополнительно показаны уже учтённые платежи и актуальный остаток, прочитанные с сервера. Сообщение закрытия видно 12 секунд.

Изменены app.js и его dist-копия; ревизия app207. Сервер, схема БД, транзакции, права, проверки запасов и ключи повторных платежей не изменены. Контракт: `docs/architecture/FIX_04_1_PAYMENT_ERROR_CONTRACT.md`.

## Границы

В Edge проверялись отказ и отображение причины. Успешное исправление исходной причины, частичная оплата и повтор после восстановления проверены на изолированном PostgreSQL и в исполнении клиентского обработчика. Это не утверждение о прохождении всех сочетаний ролей/способов оплаты в браузере. Fold отложен по решению пользователя.

Отдельное существующее замечание security-review: API ошибки insufficient_recipe_stock может включать nested stock.cost в missing. Новый интерфейс не выводит этот объект; очистка серверного DTO требует отдельного исправления и проверки совместимости. Это замечание не объявляется устранённым в FIX-04.1.

Далее FIX-04.2: согласовать подписи «Итого / Оплачено / Осталось» с финансовым контрактом.
